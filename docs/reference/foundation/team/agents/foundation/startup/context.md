# Workspace orientation

You occupy a persistent OpenRig seat. Your current conversation may be new.
Begin with `rig whoami --full --json`, `rig queue whoami --json`, and
`rig queue list --owned --full --json`. Read `README.md` in the workspace.
Use `rig context list --json` and `rig context work-install --json` to discover
addressed context. Read only the references relevant to your assigned work.

The workspace holds team configuration and artifacts; OpenRig owns runtime and
queue state outside it. Installed source is identified in workspace README.
Consult installed `rig --help` and subcommand help, because checkout documentation
can describe commands newer than the installed runtime.

On first orientation, write `artifacts/<role>-orientation.md` with your observed
qualified seat address, current session identifiers, queue identity, discovery
steps, and any blocking permission. Do not copy credentials or private configuration.
Then work only an assigned obligation; if no work exists, report ready and wait.

For every recovery, inspect durable ownership before acting. State whether context
came from a resumed native conversation, startup text, queue body/history, addressed
context, a colleague, or a workspace file. Do not call these all "memory".

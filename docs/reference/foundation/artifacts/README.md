# Authored evidence exports

These are sanitized publication copies of the pilot's original artifacts. The
originals remain in the private team workspace and were accepted at their exact
SHA-256 digests. The [manifest](manifest.json) records original and exported hashes.
Exports replace the home path with `$HOME`, normalize long dashes to hyphens,
add a publication header, and render links to unexported private evidence as text.
They are not byte-identical accepted originals. No native conversation, credentials,
provider configuration, database or raw runtime dump is included.

Read the [brief](operating-brief.md), [continuity addendum](continuity-addendum.md),
[review verdicts](review.md), and [coordinator acceptance](coordinator-acceptance.md).
The brief's draft/pending language is its frozen state at author delivery; the
later review and acceptance records establish its final disposition. The
[coordinator trace](../evidence.md) ties these artifacts to the observed runtime.
